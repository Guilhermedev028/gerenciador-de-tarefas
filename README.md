# Gerenciador de Tarefas com Integração ao Google Agenda

Este é um projeto em desenvolvimento que visa criar um **gerenciador de tarefas** simples e eficiente, com uma **integração direta ao Google Agenda** para sincronizar suas tarefas e compromissos.

## Funcionalidades
- **Cadastro de Tarefas**: O usuário pode adicionar tarefas com título, descrição, data e hora.
- **Armazenamento Local**: As tarefas são armazenadas em um banco de dados **SQLite**.
- **Interface Gráfica**: A interface foi construída com **Tkinter**, oferecendo uma experiência visual e interativa.
- **Calendário Interativo**: O widget **Tkcalendar** é utilizado para selecionar as datas das tarefas.
- **Sincronização com o Google Agenda**: As tarefas cadastradas podem ser sincronizadas com o Google Agenda através da API do Google.

## Tecnologias Utilizadas
- **Python**: Linguagem de programação principal.
- **Tkinter**: Biblioteca para a criação da interface gráfica.
- **SQLite**: Banco de dados local para armazenar as tarefas.
- **Google Calendar API**: Para integração com o Google Agenda e sincronização das tarefas.
